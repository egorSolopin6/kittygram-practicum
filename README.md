## Проект и запуск

Учебный проект по теме 6: витрина котов, голосование, дневной и недельный рейтинг.
Работает в Docker Desktop на macOS, Windows с Linux containers и Linux.

Базовый практикум, достижения и OpenAPI: [README_PRACTICUM.md](README_PRACTICUM.md).
Документация в браузере: http://localhost:8000/api/docs/.

## Быстрый запуск

1. Запустите Docker Desktop и дождитесь состояния **Engine running**.
2. Откройте терминал в этой папке. Создайте локальные настройки и запустите проект:

```sh
python3 setup_env.py
docker compose up -d --build --wait
```

В Windows вместо `python3` можно использовать `py`. Если Python не установлен,
скопируйте `.env.example` в `.env` и замените оба значения `replace-...` своими
случайными значениями. Все остальные зависимости устанавливаются в контейнере.
На Mac также можно открыть `start.command` после запуска Docker Desktop.

Если раньше использовалась Colima, переключитесь перед запуском:

```sh
docker context use desktop-linux
```

Откройте [админ-панель](http://localhost:8000/admin/).
Первый запуск автоматически создаёт таблицы, роли, котов и историю голосования.
База хранится в Docker volume `kittygram_data`.

## Пользователи и доступ

Пароль всех демонстрационных учётных записей — значение **DEMO_PASSWORD**
в локальном файле `.env`. Пароли уже существовавших пользователей сохраняются.

| Логин | Роль | Доступ в админке и личном API |
|---|---|---|
| `demo_admin` | Администратор | Все коты, создание пользователей, назначение групп и владельцев |
| `anna` | Владелец | Просмотр, создание, изменение и удаление только своих котов |
| `boris` | Владелец | Только свои коты; не видит личные записи anna |
| `viewer` | Наблюдатель | Только просмотр своего кота «Облако», без изменения и голосования |
| `demo_voter_01` … `demo_voter_12` | Участники голосования | Голосование и свои голоса через API; без входа в админку |

В публичной витрине и рейтингах доступны только ID, имя и цвет кота.
Владелец и год рождения доступны в личном API лишь владельцу или администратору.
Прямой запрос чужой личной записи возвращает 404. Флаг `is_staff` сам по себе
не даёт доступ ко всем котам.

## Адреса

| Адрес | Назначение |
|---|---|
| `/admin/` | Русскоязычная админ-панель и управление пользователями |
| `/api-auth/login/` | Вход в браузерную версию REST API |
| `/api/cats/` | Личные коты; администратору доступны все |
| `/api/cats/mine/` | Только собственные коты даже для администратора |
| `/api/showcase/cats/` | Публичная витрина для голосования |
| `/api/showcase/day/` | Кот дня |
| `/api/showcase/week/` | Рейтинг за последние семь дат |
| `/api/showcase/my-votes/` | Свои голоса после входа |
| `/health/` | Состояние приложения |
